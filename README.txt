🤖 ChatBot com Inteligência Artificial

📌 Apresentação do Projeto

Este projeto foi desenvolvido durante um curso intensivo de Python, com o objetivo de colocar em prática os conhecimentos adquiridos em programação e integração com Inteligência Artificial.

O código apresenta a estrutura básica de um ChatBot com IA, desenvolvido em Python, utilizando Streamlit para a interface e a biblioteca OpenAI para comunicação com o modelo Google Gemini.

O projeto é voltado para fins educacionais e demonstra como construir uma aplicação capaz de receber mensagens, enviá-las para um modelo de Inteligência Artificial e apresentar as respostas ao usuário.

💻 Estrutura do Código

O código foi organizado em 15 etapas:

Conexão com a IA: configuração do cliente para comunicação com o Google Gemini por meio de uma API.

Título e descrição: criação da apresentação da aplicação utilizando Streamlit.

Memória da conversa: inicialização de uma lista para armazenar mensagens durante a sessão.

Histórico de mensagens: exibição das mensagens anteriores.

Campo de entrada: criação de uma caixa de texto para o usuário.

Validação da mensagem: verificação do envio de uma mensagem.

Exibição da mensagem: apresentação do texto enviado pelo usuário.

Dicionário: organização da mensagem utilizando role e content.

Armazenamento: inclusão da mensagem no histórico com .append().

Comunicação com a IA: envio das mensagens para o modelo Gemini.

Processamento da resposta: extração do conteúdo retornado pela API.

Exibição da resposta: apresentação da resposta gerada pela IA.

Organização da resposta: transformação da resposta em um dicionário.

Atualização do histórico: armazenamento da resposta para manter o contexto da conversa.

Tratamento de erros: identificação de falhas na comunicação, incluindo erros 429 e 503.

🛠️ Tecnologias Utilizadas

Python

Streamlit

Biblioteca OpenAI

API Google Gemini

📚 Finalidade

O projeto tem caráter acadêmico e foi desenvolvido para demonstrar conceitos de programação Python, estruturas condicionais, listas, dicionários, laços de repetição, tratamento de exceções e integração com APIs.
